# 贡献与审阅

Researcher 建立证据，Translator 保留原意，Creator 提供明确许可，Developer 维护接口，Cultural Contributor 自述地域经验，Curator 给出精选理由。维护者尚未指定个人；真实人选应在公开发布前补齐。

文化贡献至少经过一位具备相应能力的人工审阅者；复杂/争议材料寻求独立第二审阅。AI 不能充任人类审阅。工程 PR 由维护者复核校验和测试，协议变更同时迁移所有消费者。

任何参与者可以指出引用/许可错误；维护者先标记或隐藏高影响错误，再核查、更正与记录。作者可以申请撤回表达，公共档案只保留必要且不侵犯隐私的变更信息。精选不代表整个国家/文化，不以国籍投票替代质量审核。
