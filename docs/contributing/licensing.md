# 许可证与资产边界

代码采用根 LICENSE 的 MIT：包括源码、构建脚本、测试与工程配置。这里不推定文化资料、研究摘录、音视频或第三方素材自动受 MIT 许可。

本轮原创工程文档与 assets/docs 的说明图按 MIT 提供，图表 manifest 明确 scope。建议未来原创文化文章/数据描述在权利人同意后采用 CC BY 4.0；当前没有已发布文化语料，不能追溯为外部资料授予该许可。第三方来源保留原许可；短摘录不等于拥有再许可权。

媒体逐项声明 creator/source/license/rights_status/sha256/bytes/alt/ai_generated/generation_record。AI 产物记录工具、日期、输入授权、生成与人工改动，不推定必然有版权或无侵权风险。授权未明不得进入发布产物。

大模型/原始视频/原始音频不提交普通 Git；有实际需要时启用 Git LFS 或版本化对象存储并记哈希，当前不引入 LFS 依赖。忽略的私人文件不因同处工作区而变为开源。

音乐投稿的具体许可选择、AI 披露、`needs-review` 权利状态与人工发布门槛见 [Community Expression Protocol](../protocol/community-expression.md)。CC0、CC BY、CC BY-NC、Custom 均不因提交而自动获准用于所有场景；必须核对第三方输入与实际使用范围。社区作品不自动适用根 MIT。
