# 立春 MVP 内容简报 · Lichun Minimum Content Brief

状态：准备稿（2026-09-18）。本文件定义立春首版文化内容的范围、验收与责任分配，供负责人审核 [立春最小内容审核包](../research/lichun-minimum-content-review-package.md) 时参照。来源锚点：[PRD V0.2](../../Solar24-24节气项目简述.md)、[产品架构](../../02-product-architecture.md)、[PRD 回归审计](../research/knowledge-base-prd-audit-2026-09-18.md)。

## 1. 目标读者

完全不了解中国文化和二十四节气的全球读者。假设零前提知识：不知道"节气"、不知道农历、不知道黄经。所有术语首次出现必须当场解释（见术语表）。

## 2. 阅读时间与形态

约 3–5 分钟：一句话引入 → 短摘要 → 可展开的四段故事（对应未来页面的折叠结构）。首版同时提供纯静态文字路径——不依赖任何动画/音频即可完成同等阅读（无障碍与"Culture > Experience"原则）。

## 3. 读者需要理解的六个问题（理解目标）

1. 二十四节气是按**太阳在一年中的位置**划分的时间刻度，不是天气预言。
2. 立春是这个序列的第一个刻度（太阳到达黄经315°，公历2月3-5日；黄经概念配一句直观解释）。
3. 立春与春节（农历正月初一）是**两套规则**的日子，不是同一个概念。
4. 立春**不等于**所有地方同时变暖——天文刻度与各地实际入春是两个问题。
5. 能说出**一个具体地方**的人如何回应这段时间（案例需带地点与时间范围）。
6. 理解上述事实之上的文化解释，且知道它是**解释**（不是"所有中国人的统一自然观"）。

## 4. 首版包含 / 不包含

**包含**（对应审核包 6 条命题，数量服从故事需要）：

| # | 命题 | 对应审核包条目 |
|---|---|---|
| 1 | 节气=太阳周年位置刻度（黄道24等分、每段15°） | LC-1（含共享卡引用） |
| 2 | 立春=序列第一、黄经315°、公历2月3-5日 | LC-1/LC-2 |
| 3 | 立春≠春节（两套规则；腊月/双立春实例） | LC-3 |
| 4 | 立春≠同时变暖（定义对照：气象入春按当地气温另行判定；不写算法与具体城市数字） | LC-4 |
| 5 | 一个传统自然观察（三候之一二，标明古典文本） | LC-5 |
| 6 | 一到两个地方生活案例（九华立春祭=立春日；石阡说春=春节或立春起、春分止） | LC-6 |
| 7 | 文化解释（interpretation 收束，明确标注） | LC-7 |
| 8 | 开放邀请："这个时间在你生活的地方意味着什么？" | LC-8（无事实依赖） |

**深圳案例处置（2026-09-18 复核收口）**：深圳 1991-2020 年平均入春日（2 月 3 日）为已核数据，但首版故事**不使用**——判据转写易失真且单城数字增加审核负担；数据与机构口径保留在知识卡层，未来需要城市锚点时另行过审。解释卡、审核包 LC-4 与本简报三处同步。

**不包含**（明确暂缓，非首版前置条件）：复杂置闰算法与节气/中气机制细节；三候完整考证与现代物候验证；饮食习俗地图（咬春仅以清代文献层出现）；UNESCO 身份叙述（解释卡保留一句，首版故事不依赖）；17 张全球候选的补证与展示；任何音频/3D。

**选用即依赖**：故事实际使用的每一句话都必须能映射到审核包条目；未列入审核包的内容不得出现在首版。

## 6. 后续轻互动（学习目标与静态替代）

在内容获准后开发（工作包 C），首版互动只做一个：**24 节点太阳位置示意**——选中立春，回答"这个刻度说明什么、不说明什么"。标注为示意图，不冒充精确天体模拟或天气预报。学习目标：把问题 1、2、4 从"读到"变成"操作过一次"。静态替代：一张等价信息的静态图 + 文字说明；键盘可操作、减弱动效、无声音。暂不做：春牛仪式游戏化、三候自动解冻动画、音乐。

## 7. 如何判断读者真正理解了（形成性测试方案）

**方案（本轮只制定，不执行、不虚构结果）**：邀请约 5 位不了解节气的读者（同事/朋友即可，无需抽样代表性），给 3–5 分钟阅读或体验后，用自己的话回答：

1. 二十四节气依据什么划分时间？（期望：太阳位置/太阳运动，而非天气或月亮）
2. 立春是否意味着所有地方同一天变暖？（期望：不是；能说出"刻度≠各地气温"的区分）
3. 能说出一个具体地方的人如何回应这个时间吗？（期望：任一案例的地点+大致时间/形式）
4. 这个时间在你生活的地方有什么不同？（观察表达意愿，不按标准答案评分）

判读：前三题检查理解（建议至少 4/5 答对方向为通过；答错处回流修改解释再测）；第四题检验参与意愿。这是形成性测试，小样本成功不构成统计学证明，也不代表全球普适性；误解驱动迭代，通过后再考虑第二个节气（春分或雨水，依反馈定）。
