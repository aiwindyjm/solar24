# How Solar24 Is Made · 制作过程

[English](README.en.md) · 简体中文 · [返回项目](../../README.zh-CN.md)

Solar24 从“怎样让人感到节气”出发，经过五版视觉与交互探索，形成了一本可漫游的节气介绍书。2026 年 9 月 20 日，第五版通过 Cloudflare 上线。这里把研究、设计选择、代码和实际发布串起来，让后来参与的人理解每一步为什么这样做。

## 从文化问题到体验

最初的入口是世界历法与年轮。反馈推动我们减少百科式文字，把日历留在画面中，再以蝴蝶、水墨和五个环境色彩角色表达季节。第四版把“观四时、望天地、听人间”放进同一个持续存在的场景；第五版进一步解决阅读、语言、天文解释和每个节气的参与方式。

现在，读者可以先在年轮上选择节气，感受环境变化，再舒展一卷阅读；抬头看太阳与地球，最后回到茶、水、收获与冬藏等生活动作。研究提供解释依据，视觉和声音提供感受入口。

## 关键改变

- **读时间，而非翻日历页**：日期原位展开，漫游按天推进，跨参考日期才切换节气。
- **一卷一个主题**：五个入口分别展开自然、物候、农事、生活、意义；蝴蝶不随阅读移动，底部控制保持可用。
- **听人间可以参与**：聆听、写意动作和记忆问题按节气配置，避免复制观四时的阅读入口。
- **解释在站内完成**：正文和书目随静态站点发布，外部原文只供延伸阅读；内部研究状态留在开发记录。
- **把语言放进链接**：英文与中文链接独立，刷新、切换节气和分享时保留语言。

每次调整的反馈、原因、取舍和验证见 [V1–V5 演进](prototype-evolution.md)。开发者的浏览器检查与真实读者的理解测试分别记录；目前没有以浏览器测试代替跨文化用户研究。

## 下一轮的顺序

1. 用立春组织小规模读者观察：能否解释节气与当地天气的区别、读懂三种尺度。
2. 逐项核对将进入生产模块的正文、译文、来源与媒体使用范围。
3. 在低性能真机上测量加载、GPU 和长时运行，再决定拆包、延迟加载与视觉降级方案。
4. 按实际共用需求将验证过的能力迁入 Host / module-runtime；保持 Host 不读取知识库。
5. 明确组织者和审核安排后试行一次小规模声音征集，再考虑社区播放器。
