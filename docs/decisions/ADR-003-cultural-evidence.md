# ADR-003 · 文化证据与创作表达分层

## Context

研究 Vault、生产内容和社区艺术表达已有不同职责。 记录日期：2026-09-20；AI 辅助文档整理，未代填人类批准。

依据：[既有决策](../architecture/decisions.md)、[总架构](../architecture/overview.md)、[Journey](../development-journey/README.md)。

## Problem

艺术解释、AI 候选或自动检查容易被误认为文化权威。

## Options

直接从笔记发布；人工审核后显式内容 PR。

## Decision

继续研究 → 人审 → 显式生产 PR；Journey 链接原证据，社区音乐明确标 community。

## Why

保证事实、解释、个人经验和创意可分辨。

## Trade-offs

审核较慢；机器只能辅助完整性检查，不能代签、自动批准或发布。

## Status

Recorded existing decision（不改变现有人工审核）。没有补写虚构 reviewer；未来变更按 [ADR 规则](README.md)处理。
