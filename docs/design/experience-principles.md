# Experience principles

先写理解目标与证据，再选择媒介。例如雨水的雨应解释地域/时段内降水经验，而不是声明全球同日下雨；白露场景须区分露形成条件和文学意象；冬至光照叙事须标纬度与半球。

最低层为可读语义 HTML；静态图→解释性二维交互→必要时 WebGL。用户可以跳过、暂停、返回，键盘与触摸具有等价路径。遵守 reduced-motion，失去可见性时暂停，恢复尊重用户设置。当前骨架无持续动画，后续不得通过空测试宣称具备完整访问性。

性能预算初始目标：公共首屏 JS gzip <200KB、无自动加载3D/声音、图片响应尺寸、错误可恢复。真实体验引入后在明确设备/网络下记录性能数据；这些是设计目标，不是已测量成绩。每个体验验收应能让初次接触者回答 WHAT/WHY/NATURE/PEOPLE，未来用小规模用户访谈验证。
