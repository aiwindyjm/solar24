# 第五版 · 介绍书与时间轴

本轮范围：`docs/design/solar24-v5/`、`tests/design/solar24-v5.test.ts`。验收重点是日期与节气同步、24 节气五章双语内容、独立章节折叠、来源可追溯和静态部署。第四版及生产 Host 保持原样。

## 内容组织

`src/book-copy.ts` 保存 24 × 5 个中英文编辑段落；`src/Book.tsx` 负责章节阅读，`src/ReadingScroll.tsx` 提供只在观四时出现的磨砂手卷。顺序为自然、物候、农事、生活、意义。介绍从读者能理解的景物、工作和生活进入，避免研究占位文案。物候章另解释三候与约五日时段的关系；意义章明确为当代观察邀请。

听人间改由 `src/Life.tsx` 独立承载三种参与交互，聚焦听觉、劳动过程和个人记忆；不重复知识章节。水岸声音沿用合成环境音，默认关闭；田间四阶段为项目创作；灯下文字只写入本机 localStorage（逐节气保存，180 字符上限，可删除，保存失败会提示）。没有新增民俗事实断言或模拟地方唱词。参与某处时其余景物标记暂隐，退一步后恢复，避免文字与标记重叠。

`src/book-provenance.json` 是本次选编的静态引用快照，关联 142 张知识卡、145 条来源记录。保留卡片 ID、标题、地域、时期、原有状态，以及来源链接；不带研究全文、私人配置或附件。章节级引用支持回查，并不等于新增命题已经逐句获得人工审核。

读取并遵循了 `docs/research/ai-research-workflow.md` 和 `skills/solar24-cultural-research/SKILL.md`；执行只读路由回放，报告存于本地 `.tmp/v5-book-routing.md`。这次是用户要求的本地原型编辑，不是文化审核通过或公开发布。知识卡及其 human_review 均未修改，原型编辑状态为 draft、humanReview 为 null。中英文均需人工审核，来源记录标题保留原文，未伪造已翻译的书目。

特别处理的内容边界：立春不等于春节；四立不等于各地气象入季；小雪、大雪节气不等于天气预报等级；古典动物转化与“祭祀”叙事不作现代生物事实；农谚不作全国播种指令；广汉保保节、尾牙、重阳、三伏等保留各自日期规则。石阡说春、湘西赶秋、椒江送大暑船等以具体地域介绍。原村落仍为艺术布景。

## 时间轴

`src/timeline.ts` 内置香港天文台年历的日级日期：

- [2026 公历与农历日期对照表（英文文本）](https://www.hko.gov.hk/en/gts/time/calendar/text/files/T2026e.txt)
- [2027 公历与农历日期对照表（英文文本）](https://www.hko.gov.hk/en/gts/time/calendar/text/files/T2027e.txt)

本轮实际下载并读取两表，使用节气日期列，没有引入农历算法。表中日期属于香港 UTC+8；程序以 UTC 午夜数字作为日历日期的内部编码，不把它解释为真实交节时刻。

漫游周期为 `[2026-02-04, 2027-02-04)`，365 个历日。每拍 600 毫秒推进一日，跨越日级边界才切换节气，不假定每个节气恰好十五天。完整周期后循环回参考立春。轮盘标记在相邻参考日期间插值，仅作阅读提示，不是实时计算的黄经。

日期与选中节气由同一个时间轴更新。定时器只保留一个；暂停或页面隐藏时清除，恢复后重新从当前日走动。打开日历不影响计时；手动选择停止漫游。URL 记录节气和视角，同一标签页的 history.state 记录所选历日，支持刷新和前后退恢复；在新标签页打开分享链接时，回到该节气在参考周期中的起始日。

## 静态交付与字库

`vite build` 的 `dist/` 即静态站点文件。新正文没有运行时 API、数据库请求或 Host 对知识库的导入。离线查看本地已载入内容不要求后端服务；正式分发仍需一般静态文件托管，不宣称已实现离线缓存或 Service Worker。

中文文楷、毛笔、小篆已根据新正文及出处重新生成子集。`scripts/subset_fonts.py` 校验原文件 SHA256、保留版权/OFL、重命名衍生字体，并更新 assets/public 两处 manifest。原始字体未改变。篆书覆盖有限，正文缺字仍按原设计回退。
