# Solar24 V · 可漫游的节气介绍书

第五版独立于第四版，预览端口 **5176**。在同一山水环境中优化阅读、字体与天文解释，没有修改生产协议或人工审核状态。

## 交互

- 无指定语言和历史偏好时默认英文。`?lang=en` / `?lang=zh` 优先指定分享链接的语言；切换时更新 URL。语言、英文和中文字体各自保存于本机；切换语言不会覆盖另一语言的字体。
- 顶部 `Aa / 字` 打开字体选择。英文：Libre Baskerville、Cormorant Garamond、Source Sans 3；中文：霞鹜文楷、马善政毛笔、霞鹜篆书。三款中文字体提供网页子集，篆书未收字回退文楷；没有伪装完整的甲骨文或隶书字体。
- 印章固定小篆，使用字体确有的 `廿四 / 春風 / 夏日 / 秋月 / 冬雪 / 人文 / 日月 / 春夏秋冬`；字形覆盖已经检查。
- 时间盘分节气节点、太阳黄经、四季编组、八卦符号四层。悬停／键盘聚焦会加深，点击／Enter／Space 可固定说明，再次激活取消；手机可点按各环。八卦是传统符号的艺术层，不充当天文坐标或指南针。
- 望天地默认太阳周年。标明太阳、地球、二分二至、日地连线，显示所选节气的太阳黄经及地球相反的日心方向。地轴倾角约 23.44°，在模拟公转中保持方向；地球近观仍可操作。
- 英文说明、标题与阅读卡片提供英文草稿。节气汉字及印章作为文化字形保留，按钮的英文辅助名称可读出对应节气。
- “漫游一年”每次从 2026-02-04 立春开始，每 600 毫秒推进一天，约 3 分 39 秒循环一周。节气在参考历日边界切换，轮盘标记按日移动；日历展开后仍会走动，年末进入 2027 年，完成后回到这组参考周期的起点。
- 暂停和页面隐藏停止时间轴，恢复时不补跳。手动选日期、节气、视角或打开阅读区结束漫游。减少动态模式仍允许主动启动逐日漫游，但不播放环境转场。
- 日历支持 2026、2027 两个参考年，选日期同步选择节气。日期依据香港天文台 UTC+8 日级表，不使用访问者时区转换，也不计算农历或精确交节时刻。
- 观四时：五个入口分别展开自然卷、物候卷、农事卷、生活卷、意义卷，每卷仅包含对应主题，不再排列其他章节。换卷重新舒展并从顶部阅读；阅读依据与延伸原文可折叠，地域适用范围保留在正文。右侧节气题签可重开当前主题。半透阅读区只覆盖主画面，卦象、漫游、主题入口和日历继续可操作；开始漫游会收卷。纸面、墨色、细线随节气环境色变化，蝴蝶年轮位置与尺寸不变。手机正文与入口可同屏查看，减少动态模式直接展开。设计演进见 [手卷设计研究](SCROLL-RESEARCH.md)。
- 听人间：24 节气各有三个场景入口、聆听提示、参与动作与记忆问题。14 类写意交互随节气变化，例如谷雨舒茶、芒种收种接续、大雪覆护、冬至点染 81 个消寒计数墨点。声音为主动开启的合成音景，随节气柔和变化；记忆按节气仅存当前浏览器，可删除，不上传。相关生活背景与本地书目原位折叠展开，没有复用观四时手卷。交互不是实际农事指导或仪式复原。详见 [节气生活设计](LIFE.md) 与 [验证记录](LIFE-VALIDATION.md)。
- 望天地：聚焦天体观察和已有天文说明，不再重复放置五类阅读入口。视角切换关闭手卷，保留日期、节气和声音设置。
- 正文、章节引用、字体和素材均打包为静态文件，无后端、无运行时知识库读取。外部来源只有在读者主动点击时打开。

## 面向读者的内容与出处

正文与本地书目可直接在站内阅读。观四时、听人间及望天地的「阅读依据」展示文献名、发布机构与原文语言，外链收在二级延伸阅读中。读者界面不再展示内部草稿状态、笔记编号或研究备注；地域与时代保留在正文，原始审核记录保持不变。详见 [出处与内容边界](READING-REFERENCES.md)。本节取代上文历史描述中面向用户展示“研究状态”的做法。

## 运行

从仓库根目录执行：

```powershell
pnpm exec vite --config docs/design/solar24-v5/vite.config.ts --port 5176 --strictPort
pnpm exec tsc -p docs/design/solar24-v5/tsconfig.json
pnpm exec vite build --config docs/design/solar24-v5/vite.config.ts
```

字体全部本地托管，OFL 原文、字体来源及子集 SHA256 记录位于 `assets/fonts/`。字体子集重新命名为 Solar24 Reading / Solar24 Seal / Solar24 Brush，保留原作者版权与 OFL；没有用原作者的保留名称命名衍生字体。英文文件只转换为 WOFF2。

## 研究与边界

见 `RESEARCH.md` 与 `BOOK.md`。这是圆轨道、非实际比例的教学场景，不计算实时星历或交节时刻。四季与自然环境为艺术诠释；本轮按用户要求在本地原型中选编知识库内容，形成 24 节气的介绍章节，编辑与翻译仍是待人工核验的草稿。未改动第四版、原始素材、生产 Host 或知识库审核状态。
