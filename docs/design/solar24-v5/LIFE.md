# 听人间 · 节气生活

本轮仅修改第五版原型。每个节气提供三个入口：停下来听、亲手观察一种变化、留下一段自己的记忆。入口名称、双语引导、动作和记忆问题都随节气改变，继续使用同一片山水与节气色彩。

## 内容与技术边界

- 背景文字复用现有 `book-copy.ts` 双语编辑稿；来源来自静态 `book-provenance.json`。自然观察对应自然章节，农事动作对应农事章节，茶、消寒与家庭记忆对应生活章节。
- 地域、来源与草稿状态按需展开。没有更改知识库人工审核状态，也没有新造历史引文。地方生活例子不推广为全国一致习俗。
- 动作是当代艺术表达，不是农事操作建议、气象预测或地方仪式复原；大雪不保证当地落雪，节气也不等同于农历节日。
- 合成环境声使用单一 AudioContext，节气改变时平滑调整音色与呼吸节律；暂停、隐藏页面时挂起，关闭时释放。不是自然或民俗现场录音。
- 节气记忆沿用 `solar24-v5-memory-{slug}` 本地存储，无后端。场景动作不持久化。
- `life-data.ts` 管理内容，`SeasonDrawing.tsx` 绘制，`LifeContext.tsx` 显示背景，`Life.tsx` 组织交互。没有新增环境渲染循环。
- WebGL 不可用时，HTML 入口、SVG 动作与记忆功能仍可使用。观四时的五个独立手卷保持原有分工。
