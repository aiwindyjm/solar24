# 面向读者的介绍与出处

2026-09-20，范围：第五版的观四时、听人间背景阅读、望天地说明及页脚。

## 读者界面

- 移除本地原型、编辑与翻译草稿、待人工核验、知识卡 ID、内部研究状态及直接导出的长篇地域研究备注。
- 正文仍保留地域、时代、古典文本与现代解释的区别。天气随地点变化、艺术动作与实地农事不同、教学轨道不按真实比例等与理解有关的说明保留。
- 「阅读依据」在本页提供文献题名、机构与原文语言。题名沿用静态来源记录，未伪装成已出版的英文译名。
- 外部地址收在二级的「延伸阅读 · 原文网站」中；显示域名与语言，明确在新标签页打开。阅读正文和书目不需要访问原站。
- 观四时、听人间、望天地共用原型内部的 References 组件。无来源的当代观察邀请不生成空书目。
- 不热链外站图像、字体、音频，不增加可达性检测 API，不用代理复制来源全文。所有正文与书目在构建时打包。

## 核验与发布边界

这次改变读者的信息组织，不等于完成事实、翻译或许可审核，不修改 `book-provenance.json`、知识库状态或生产 Host 门槛。

本次检查静态引用快照：145 条来源都有 direct-read 记录；129 条记录为 cross-checked，16 条为 unverified。该字段是研究记录，不是本次测试结论，也不能代替逐句人审。章节编辑状态仍为 draft、humanReview 仍为 null。记录原样留在内部，不把去掉界面提示当作 approved。

本轮没有重新逐一校验来源全文，也没有测试各国网络是否能访问原站。产品通过本地正文和本地书目解除阅读对这些链接的依赖，不声称外链全球可达。公开发布前的内容核验继续按仓库工作流执行。

## 验收标准

- 24 节气的五类介绍和生活背景无需外部请求；关闭所有站外网络仍可阅读正文和书目。
- 中英文不展示研究流程状态、笔记编号或研究地域原始字段。
- 原站链接默认不可见，只有主动展开二级入口后才可操作；显示站点、原文语言和新标签页行为。
- 保留每章静态引用、地域适用范围和内部审核记录。
- 桌面与手机检查书目滚动、长标题换行、五个独立卷轴及天文阅读。

## 实际验证

- Chromium 屏蔽全部站外 HTTP 请求：中英文共 240 次章节阅读、48 次生活背景阅读通过，实际没有发起站外请求，无未捕获页面异常。
- 各事实章节展开后有本地题名与机构，原文链接默认隐藏，二级展开后可操作并使用新标签页；当代观察章节没有空书目。
- 天文说明保留两条本地书目，外链同样折叠。
- 检查 1269×1066、1280×720 和 390×844 布局；手机无页面横向溢出。截图在 `output/playwright/solar24-v5-reading-references-desktop.png` 与 `solar24-v5-reading-references-mobile.png`。
- 第五版独立 TypeScript、Vite 构建、修改源码的 Prettier 检查通过；仓库 lint、74 项测试、build 及生产 Host 的 2 项端到端测试通过。端到端使用已有本地配置 `.tmp/solar24-v3-e2e.config.ts`（4183 端口）。
- 构建仍有 Zod 注释警告与第五版 JS 包大于 500 kB 的提醒；没有调整检查阈值。
