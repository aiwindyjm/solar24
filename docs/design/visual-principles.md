# Visual principles

Solar24 独立品牌，以“观察自然的时间档案”为叙事方向。读者对中国文化陌生，因此层次清晰、说明图可读、文化术语有解释比装饰重要；不使用未经研究的“东方符号”堆叠，也不把 Morpho 作为默认品牌。

设计取向：安静（观察与阅读）、整齐（资料可核查）、疏密交替（故事与24项索引）、中等字重（中英清晰）、好奇而尊重。README 本轮使用原创代码绘制的顺序示意 SVG，不是假装已有自然照片或正式体验。

初始可用 token：背景 #FAFAF7、正文 #243329、链接 #235B50、焦点 #9C462C、分隔 #B5BFB6；大段正文16px起/1.7行高，标题 clamp，间距8/16/24/32/48，主要点击区至少44px。季节色只做导航辅助，始终带文字。当前 token 在 Host CSS 集中，出现共享组件后再抽 ui 包。

阅读宽度不超过72rem；手机单列自然流，24项导航自适应网格；键盘焦点、hover、当前项都有形状/文字提示，不能仅靠颜色。正文对比4.5:1，关键控件3:1。媒体必须有 alt、来源、许可、静态替代；图片裁切不能改变事实含义。

根 README 以 Hero→概览/四季→顺序环→体验占位→架构/路线组织。图示明确“非天气预报、非精确日期/天文尺度”。后续正式品牌设计再开展参考研究，本轮用户授权的本地 SVG/明确占位优先于素材采购或图像生成。
