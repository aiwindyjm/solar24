## 浏览器实测

通过 Playwright CLI 使用本机 Chromium 检查：

- 1258×1066、1280×720、390×844 布局与截图；手机无页面横向溢出。
- 三视角往返后 canvas 数量为 1，并检查节点身份仍是同一画布。
- 24 个节气逐个选择，48 张大小蝴蝶图均成功解码。浅底、深底对照图保存在输出目录；艺术纹饰与原图对应关系仍应由素材所有者最终确认。
- 立春故事区、手机故事区、来源说明的 DOM 入口保留。
- 快速切换后浏览器返回恢复视角；日历展开聚焦选中日期，Escape 收起后焦点回到触发按钮。
- 暂停后连续采样帧计数不增加；减少动态模式同样停止帧循环。
- 禁用 WebGL 后 canvas 为 0，静态模式仍可点田畦入口阅读。
- 地球近观／太阳周年、键盘旋转与缩放、复位可操作。
- 本机 1280×720 观四时场景 2 秒采样约 120 帧/秒。仅为当前设备短时样本，不代表真实手机或持续压力下的性能。
