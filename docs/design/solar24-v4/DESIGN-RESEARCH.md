# 写意山水设计记录

## 观察

中国山水画的空间不依赖把每个对象画满。远近由墨色、留白、层叠和观看路径建立；线条有速度、轻重、干湿变化，景物不必承担说明书式的形体。

## 本版转译

- 远山：固定轮廓与低对比水墨层，镜头移动而山不晃动。
- 水面：保留长段空白，只在雨季出现少量不完整涟漪。
- 人间：房屋不再作为几何模型，改为远处两三笔屋脊、墙线和灯意。
- 植物：移除重复的柳条幕墙，改用一侧十三笔以内的疏草和漂动粒子。
- 空间：生活视角靠近同一山水；天地视角抬升到真正的球体、太阳和轨道。
