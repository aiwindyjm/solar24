# Solar24 第四版 · 一片山水，三种观看尺度

第四版是独立的视觉原型，预览入口为 `http://127.0.0.1:5175/`。它保留二十四只逐一校正的蝴蝶资产，把同一片山水作为连续环境，在 `观四时`、`望天地`、`听人间` 三个尺度之间转场。

## 写意方向

主页不再摆放房屋、成排柳条或规则水纹。山水由稳定的远山、纸面留白、断续岸线和少量散笔构成；生活视角才显出几笔远舍、田畦和水岸。笔触由 `src/inkLandscape.ts` 生成，使用干笔断裂、湿墨晕染、疏密和不等长线条表达“气韵”与空间，不临摹具体画家或作品。此取向参考大都会艺术博物馆关于中国画“重在传神与用笔，而非表面写实”的公开研究资料，属于本项目的设计解释，不是文化史结论。

## 已实现

- 二十四节气蝴蝶主图与缩略图；外围八卦可显示或隐藏，中央不叠加太极图。
- 持续的 Three.js 场景：山水、雾、水、鸟、雨、落叶与季节色光；转场不刷新页面。
- `望天地` 使用真实球体、太阳、轨道、昼夜光照、云层和 Natural Earth 公版陆地数据；支持地球近观、太阳周年、拖动、滚轮、键盘和复位。
- `听人间` 的三个入口在画面中展开同一阅读区域；立春故事保留地域、来源和研究草稿标注。
- 日历原位展开，节气、视角、浏览器前进后退与深链接可恢复；声音默认关闭，支持暂停、隐藏页面、减少动态和 WebGL 静态降级。

## 运行与检查

```powershell
pnpm exec tsc -p docs/design/solar24-v4/tsconfig.json
pnpm exec vite --config docs/design/solar24-v4/vite.config.ts --host 127.0.0.1 --port 5175 --strictPort
pnpm exec vite build --config docs/design/solar24-v4/vite.config.ts
pnpm lint
pnpm test
pnpm build
```

第四版不读取 knowledge-base，也不改变生产协议。立春以外的文化卡片仍是环境观察草稿，未经人工审核；原始蝴蝶素材、前三版和研究原文保持不变。
