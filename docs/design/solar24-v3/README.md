# Solar24 V3 · 蝶见四时

本地交互设计原型，2026-09-19 收尾。保留相邻的第一版世界历法与第二版水墨宇宙文件。本目录独立于生产 Host，不改变模块发布状态，也不运行时读取 Obsidian Vault。

## 启动

在仓库根目录安装已有锁文件依赖后：

```powershell
pnpm exec vite docs/design/solar24-v3 --config docs/design/solar24-v3/vite.config.ts --host 127.0.0.1 --port 5174 --strictPort
```

打开 `http://127.0.0.1:5174/#lichun`。可直接用其他节气 slug 作 hash。无需外部字体、在线图片或服务器接口。

检查与构建：

```powershell
pnpm exec tsc -p docs/design/solar24-v3/tsconfig.json
pnpm exec eslint docs/design/solar24-v3/src docs/design/solar24-v3/vite.config.ts
pnpm exec vite build docs/design/solar24-v3 --config docs/design/solar24-v3/vite.config.ts
```

静态产物在本目录 `dist/`，可放在任意静态 HTTP 服务的子目录。请勿直接用 `file://` 打开模块脚本。项目全局检查仍为 `pnpm lint`、`pnpm test`、`pnpm build`。

## 体验

- **观四时**：24 个蝴蝶节点，更换中央蝴蝶、诗性短句、五角色配色、山水及粒子。六类动态是共享视觉语汇，不代表24个完整生产模块。
- **望天地**：太阳系公转示意与地球观察太阳视位置两种视角。可切换立春及二分二至，中央图随之变化。黄经采用 `315° + 15° × index`；日心视图中地球的简化方向与地心太阳方向相反。示意忽略偏心率、摄动、光行差、地轴、实际尺度与日期换算，不是实时星历。导航轮盘顺时针排布只是编辑顺序。
- **太极意象**：水墨轮、太极与八个卦符的艺术叠层；不宣称卦序、方向与节气有准确对应。蝴蝶可一键切回。
- **五种观察**：立春选编五类研究卡片；另外五个节气有三候草稿；其余自然卡片是明确标注的创作解释，农事等未选编的维度保留研究入口。不用未经核验的批量文字充当完成。
- **历日**：原位展开2026年公历，月尺切换、日期选择、月底截断、Esc关闭。不离开当前场景。尚未接入农历、精确交节或日期驱动节气，不应据此认定某日交节。
- **动静与声音**：暂停、系统减少动态、隐藏页面停止画布循环；声音默认关闭，由用户开启低通合成环境音。不是田野录音。WebGL不可用时保留CSS光影、SVG山水与全部按钮和正文。
- **语言**：主导航与场景短句提供英文；文化正文与部分辅助标签仍是中文，完整翻译待人工审核。

立春的柳枝、薄冰与水纹，惊蛰的萌芽和慢云光，夏季的荷影，秋季的落叶，冬季的雪粒与岸灯，都属于创作隐喻，不是地域天气或物候实测。不同节气共享动效家族，以数据决定色彩和意象。

## Solar24 Color Language

`src/data.ts` 是本原型唯一节气配置入口；每个节气的 `palette` 按顺序存五个环境角色：

| 角色          | 用途             | 立春示例  |
| ------------- | ---------------- | --------- |
| Sky · 天色    | 宣纸底与空间底色 | `#edf0e5` |
| Mist · 山雾   | 远山、雾与边界   | `#bed3bc` |
| Accent · 墨色 | 正文、轮盘、植物 | `#3d6550` |
| Water · 水色  | 水面与冷色过渡   | `#c3d9da` |
| Light · 日光  | 光晕与暖色细节   | `#e7d5a7` |

其余23套数值与创作主题同处 `data.ts`，自然卡片直接呈现对应五色。颜色名是设计角色，不是假托历史色谱的标准色名；当前也没有声称完成五行理论到数值色彩的学术映射。CSS颜色属性和WebGL背景渐变，关闭动态时画布直接更新。

## 素材与内容边界

蝴蝶来自用户提供的仓库根目录 `24节气图标.png`。`assets/manifest.json` 保留原图哈希、裁剪格子、加工方式和授权说明。按6列4行、从立春到大寒推定顺序；原图无文字标签，因此对应关系尚待用户校对。原图未修改。公开再分发许可尚未确认。

研究卡片只摘选已存在的知识库线索，保留笔记ID、适用范围和来源链接；所有事实仍待人工审核。本原型不将任何研究状态设为 approved，也不自动发布。参见 `src/data.ts` 的 `research` 与 `pentads`。

原型采用现有 React + TypeScript + Vite，加原生 WebGL、Canvas和CSS。没有为视觉预览迁移Next.js或加入动画依赖。正式接入需按Host/模块生命周期边界拆分，并通过内容审核和媒体授权。

## 文件

| `src/main.tsx`        | 时间轮、导航、原位日历与文化卡片   |

| `src/style.css`       | 宣纸、水墨、布局、动效与响应式样式 |
| `tsconfig.json`       | 独立类型检查，避免docs被根检查遗漏 |

验收范围：V3页面能独立构建；24个节点及素材可用；两种天文视角可切换；卡片键盘关闭恢复焦点；原位日历日期有效；桌面、手机均可访问核心入口；前两版不被覆盖。此范围不包括真实天文历算、24节气完整文化出版或生产Host迁移。
