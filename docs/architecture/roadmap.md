# Roadmap

| 阶段         | 交付与退出条件                                                                      |
| ------------ | ----------------------------------------------------------------------------------- |
| 当前初始化   | 24 模块骨架、Vault、协议、README、可复现安装/检查/构建；不承诺文化已审核            |
| 立春研究     | 先天文基础，后地域自然/生活；小颗粒笔记、引用、争议、人工审核，不把各地天气写成定律 |

| 全球档案     | 明确授权、精选理由、撤回与更正、版本及地域差异检索                                  |

项目状态枚举只描述模块成熟度。当前立春 Prototype 表示“工程骨架可运行”，其余 Planned；所有文化数据 draft。Researching 在实际研究任务启动后使用。Interactive 需有真正交互，Released 需文化审核、许可、可访问性和发布检查通过。
