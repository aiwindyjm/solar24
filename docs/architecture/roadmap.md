## 接下来的优先级

| 顺序 | 工作               | 完成依据                                                           |
| ---- | ------------------ | ------------------------------------------------------------------ |
| 1    | 立春读者观察       | 记录不同背景读者能否解释节气、当地天气及三种尺度；问题对应具体调整 |
| 2    | 生产内容与素材核验 | 有真实审核记录的正文、译文、来源及适用媒体许可                     |
| 3    | 真实设备性能优化   | 建立加载、内存、帧率与长时运行基线，再验证拆包或降级的效果         |
| 4    | 生产模块接入       | 先完成立春；复用明确的共享能力，不让 Host 读取知识库               |
| 5    | 小规模声音共创     | 明确组织与评审安排，跑通投稿、署名、发布与撤回，再决定播放器需求   |

以上为工作顺序，不承诺未安排的日期。V5 Demo 已上线；生产模块的文化审核、社区曲目接收、精选与协议版本各自管理，不以 Demo 上线代替这些步骤。
