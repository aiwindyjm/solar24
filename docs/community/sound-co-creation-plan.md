# Solar24 小规模声音共创准备 · Sound Co-creation Plan（2026-09-25）

> Roadmap #5：明确组织与评审安排，跑通投稿→署名→发布→撤回流程，再决定播放器需求。本文件仅做组织设计，不实现播放器。

## 一、目标

邀请 3-5 位贡献者为特定节气创作环境声音/传统乐器片段（30-120 秒），跑通完整协作流程。

## 二、五步流程

### 1. 投稿

- 渠道：GitHub Issue（已有 music-contribution form）或邮件
- 内容：音频文件（WAV/FLAC，≥44.1kHz）+ 创作说明（节气/灵感/地点/时间）+ 署名选择
- 格式要求：
  - 不含人声（环境音/器乐/合成音均可）
  - 长度 30-120 秒
  - 可循环（首尾自然过渡）

### 2. 署名

贡献者选择：
- 实名 + 链接（个人主页/社交账号）
- 昵称
- 匿名（仅显示"社区贡献"）

署名信息写入模块 assets/manifest.json 的 `creator` 字段。

### 3. 评审

- 评审人：项目负责人（初期），后续可扩为 2 人
- 评审标准：
  - 技术质量（无爆音/底噪/剪辑痕迹）
  - 文化适配（与节气氛围的关联性，由创作说明判断）
  - 版权确认（提交者声明为原创或有合法使用权）
- 评审结果：accept / request-changes / decline（附理由）

### 4. 发布

- 路径：`modules/<slug>/assets/audio/`
- 元数据写入 `assets/manifest.json`（creator/license/source/sha256）
- 许可证统一：CC BY-SA 4.0（贡献者在投稿时勾选同意）
- 模块 manifest 添加 `audio` capability

### 5. 撤回

- 贡献者可随时通过 Issue 请求撤回
- 撤回流程：Issue 确认 → 从 manifest 移除 → 文件删除 → git revert 可追溯
- 已发布的缓存（如 CDN）在下一个部署周期自然清除

## 三、许可与授权条款（草案）

```
贡献者声明：
1. 本作品为本人原创创作，或本人已获得合法授权。
2. 同意以 CC BY-SA 4.0 许可证发布。
3. 同意 Solar24 项目在任何媒介中使用本作品，包括但不限于网站、演示、衍生品。
4. 保留署名权（按投稿时选择的署名方式）。
```

## 四、试点建议

| 节气 | 主题 | 声音类型建议 | 原因 |
|---|---|---|---|
| 立春 | 冰裂/融雪 | 环境录音 | 首个垂直切片 |
| 夏至 | 蝉鸣/夏日风 | 自然录音 | 对比鲜明 |
| 冬至 | 静谧/炉火 | 氛围合成 | 与立春对称 |

## 五、与现有 Issue Form 的衔接

已有 `docs/community/music-contribution.md` 说明文档。需补充：
- 音频技术规格表（上述格式要求）
- CC BY-SA 4.0 许可文本
- 评审时间承诺（如 7 个工作日内回复）

## 六、播放器需求评估（暂缓）

跑通 3-5 个投稿后再评估：
- 是否需要独立播放器组件（vs. 使用浏览器 `<audio>`）
- 是否需要波形可视化
- 是否需要按节气混合多轨

**本文件不做播放器设计与实现。**
