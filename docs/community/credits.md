# Credits · 共同创作者

未来项目统一展示 Music、Visual、Research、Code、Translation 五类贡献，每项至少 **Name / Location / Contribution / License**。姓名可为贡献者选择的公开艺名，地点可为宽泛地区或“未披露”，不强制真实姓名或国籍。

机器结构为 [ContributorCreditSchema](../protocol/schemas/contributor-credit.schema.json)：`name / location / contribution / detail / license / url`。`detail` 说明作曲、录音、混音、研究、翻译等实际劳动；许可写明适用对象，不能把音乐许可覆盖到研究引用或代码。多人合作逐人记录，引用/采样来源同时列入 references，不用一个主创名字遮住他人贡献。

投稿接受前补齐 credits；至少包含提交创作者的 Music 记录。所有合作人的署名/许可仍由人工核对，机器不会知道遗漏了谁。AI 工具记录在作品披露中，不虚构真人 AI 贡献者。公开页面不从 contact 自动生成署名，也不默认公开联系方式。

展示格式为每项一行：名字（可链接公开主页）· 地点 · 贡献类别与具体工作 · 许可。精选卡和完整作品页都保留作者入口，Release Notes 列本次实际贡献者。本阶段没有真实名单，不创建示例人物。
