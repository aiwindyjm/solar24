# 用你的声音，表达一个节气

**为什么这段声音属于你对这个节气的理解？** 这是我们最想听到的答案。

Solar24 从中国二十四节气出发，邀请世界各地的人说说自己如何感受自然和时间。同一个节气可以有很多种声音，也可以表达差异。你不必模仿中国音乐。

## 谁能参加，能交什么

音乐人、学生、程序员、AI 音乐创作者、声音设计师、文化研究者、普通人都能参加。不要求专业设备或专业音乐背景。

可以交一句想法、一段 Demo、一首作品、田野录音、电子声音、传统乐器、AI 辅助创作、声音景观或实验音频。请告诉我们你在哪里、听见什么、为什么这样做。

| 层级                          | 你可以做的事                                                            |
| ----------------------------- | ----------------------------------------------------------------------- |
| Layer 1 · Sound Idea          | 一句话声音创意；无需音频，欢迎先在 Discussion 聊聊                      |
| Layer 2 · Sound Sketch        | 短音乐、试验或 Demo；附可听链接                                         |
| Layer 3 · Seasonal Track      | 一份你认为完整的节气作品；附可听链接                                    |
| Layer 4 · Featured Expression | 已发表作品中，由真实 Curator 写明理由选出的表达；不能自行选择或自动升级 |

短作品也可能被精选。层级不是职业等级，不按时长、国籍、点赞或是否用 AI 排名。

## 怎么提交

1. 选一个节气，阅读项目的解释与研究状态；有疑问可以先问。尚未审核的研究不能作为定论。
2. 准备作品说明与可公开访问的 HTTPS 音频链接。Sound Idea 可以没有音频。
3. 在本仓库 New issue 选择 **🎵 Submit a Solar24 Seasonal Sound**，回答下面的核心问题，填写许可和 AI 使用情况。
4. 等待补充资料、社区交流和 Curator 审阅。通过检查或被接收，都不等于已发布或已精选。

表单需合入 GitHub 默认分支才可使用。本仓库当前不提供独立上传页面。不会要求你把大 WAV 文件塞进 Issue 或普通 Git；支持 MP3、OGG、FLAC、WAV、M4A、WebM，供审听文件最多 50 MiB。优先压缩预览；大体积原始母带先保留，确有需要时与维护者协商授权存储。播放器页面链接也可提交，说明实际音频格式与时长；不知道体积/哈希可以写 unknown，审核会补核。

## 最重要的说明

- **What does this solar term mean to you?** 这个节气对你意味着什么？
- **Why does this sound belong to your interpretation of it?** 为什么用这段声音表达它？
- 灵感来自中国文化研究、本地季节、自然、个人记忆、传统音乐、现代作曲，还是其他？
- 这是你个人的经验，还是某个地方、时代、社群的实践？哪些相同，哪些不同？

可以用自己最熟悉的语言，先简单说清楚。个人记忆不要求学术引用；涉及历史、科学或传统归属时请附可查来源。别把“我在这里听见的声音”说成“中国各地一向如此”。

## 我们不想收什么

- 只有“古风”标签，没有具体解释。
- 模仿影视配乐或堆砌中国元素，来替代自己的表达。
- 没有文化解释、没有说明人工参与的 AI 音乐。
- 没有授权信息，或无法说明采样、改编、参考素材来源的作品。
- 将地方实践错误地说成中国共同传统，或冒充一个社群的声音。

**文化表达 > 风格模仿。** 尊重事实不意味着每个人必须得出相同感受。

## 许可与 AI，简单说

作品仍署你的名字。可选 CC0、CC BY 4.0、CC BY-NC 4.0 或 Other / Custom；说明版本、许可链接/条款和署名写法。非商业与定制许可需单独核对网站和传播方式，不自动获得无限使用权。授权不清就保持 `rights.status = needs-review`，不能发布。

欢迎 AI-assisted Music。请公开 yes/no；如为 yes，写工具、模型（知道就写）、生成日期、工具条款链接/版本、输入或参考材料和你实际做了什么。模型未知可以写 unknown；日期或条款未知先标明，权利审查前补齐。**工具能生成音频，不代表你一定能自由授权它。** 原创声明也不替代采样和人物录音授权。

Issue 是公开的。地点可以只写地区，国家可不披露，联系请用 GitHub 用户名或公开主页，不要填私人电话、住址或凭据。表单确认“公开投稿”与“同意网站展示”是两回事；可选择暂不同意展示。需要私密沟通时等维护者提供真实渠道，不把敏感文件放公开 Issue。

## 提交以后

Discover → Submit → Automated Check → Community Review → Curator Review → Accepted → Published → Featured

机器只查字段、已声明格式/体积等；人判断意义、文化边界、权利与选择理由。当前自动检查在元数据文件/PR 阶段运行，没有 Issue 自动回复机器人，也不自动下载外链。[完整流程](workflow.md)说明补充、更正、拒绝、复核和撤回。

你的名字、地点、贡献与许可会出现在 [Credits](credits.md)。**Accepted ≠ Featured**，精选也不代表一个国家的最佳声音。任何时候都可请求撤回展示；既有公开许可、Git 历史与第三方已取得副本无法承诺自动消失。

工程参与者可使用 [元数据模板](music-metadata-template.json)和 [Community Expression Protocol](../protocol/community-expression.md)。普通创作者只需填表。
