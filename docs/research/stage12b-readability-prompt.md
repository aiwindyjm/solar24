# Solar24 第十二阶段提示词 · 内容可读性修复（2026-09-30）

现在进入 Solar24【第十二阶段 · 内容可读性修复】。

## 目标

16 个 Stage-10 节气的命题文本从学术体改写为散文体——与 Stage 9 的 8 个节气质量对齐。

## 改写标准（对标 Stage 9）

| 项 | 标准 | 反例（当前） | 正例（目标） |
|---|---|---|---|
| 字数 | ≤120 字/命题 | 150+ 字 | ~80 字 |
| 术语 | 零未解释术语 | "阴阳合历""朔望月""置闰" | "中国传统历法""月亮周期""闰月" |
| 语气 | 讲故事，不写论文 | "反映地球绕太阳轨道位置" | "节气跟着太阳走，不跟着月亮走" |
| 结构 | 一句一个意思 | 多重从句嵌套 | 短句，每句 ≤30 字 |
| 读者 | 零中国文化背景 | 默认知道农历 | 首次出现即解释 |

## 改写范围

16 个节气 × 8 命题 = 128 条：
惊蛰/立夏/芒种/夏至/小暑/大暑/处暑/白露/秋分/寒露/霜降/立冬/小雪/大雪/小寒/大寒

## 改写方法

1. 读取每个节气的 `content/zh-CN.json` 中全部 claims
2. 对每条 claim 的 `text.zh-CN` 和 `text.en`：
   - 保留 `knowledge_ids`/`source_ids`/`reviewer`/`reviewed_at` 不变
   - 重写 `text` 为散文体（中英同步）
   - 确保事实内容与原知识卡一致（不改事实，只改表达）
3. 写回 JSON 并 validate

## 完成判据

1. 128 条 claims 全部改写（中英双语）
2. 每条 ≤120 字
3. pnpm validate + test + build + e2e 全绿
4. 重新部署
5. Playwright 浏览器验证 24/24 模块渲染正常

## 不改的

- knowledge_ids / source_ids / reviewer / reviewed_at / kind / region / period
- sections 结构
- Stage 9 的 8 个节气（已经是散文体）
