============================================================
一、总目标与总纪律
============================================================

目标：把知识库从"网页级"升级到"书籍+数据+地域级"，全程不改 Verified 流程。

总纪律（每一轮都适用，违反任何一条即该轮作废）：
1. 宁缺毋滥：读不到就记 unread/needs-research，禁止编造、补全、从检索摘要当原文。
2. 每轮七步：研究问题 → 直读来源 → 建/更新 Source（access 必填）→ 建/升级知识卡 → 跑路由引擎 → 记入当轮 log → 更新 round2-progress.md。
3. 每轮预算：抓取≤8次、新卡≤3张；质量优先于进度。
4. 每10轮（R10/R20/…/R100）checkpoint：pnpm validate + pnpm test 全绿才进下一轮。
5. 不碰人工领地：不填 human_review、不标 approved、不改审核包已有 Decision；新增卡一律 draft（按路由结果可 in-review）。
6. 不做 Web/视觉/音频生产；可视化只产"数据卡+母题登记"。
7. Skill 出错：若同类错误≥2轮出现，修引擎规则+补回归测试（tests/research/），禁止写一次性规则；修订记入 07_research/round2-progress.md 的 Skill 修订表。
8. 与 P0 人工审核并行不悖：不等待审核结果，但绝不代替审核。

三、100 轮任务分解
============================================================

【阶段0 · 准备】R01–R03
- R01：创建 knowledge-base/07_research/round2-progress.md：100轮清单表（轮号/阶段/目标/状态/产出/日志链接），本文件为唯一进度真相源；断点续跑规则=新会话先读它，从第一个未完成轮继续。
- R02：建立抓取手册 knowledge-base/07_research/source-fetchability.md：汇总既有实测（维基文库API检索式、ihchina curl直连+302、代理 127.0.0.1:7897 仅境外站、ctext/UNESCO拦截、防幻觉高危点清单），此后每轮新发现的可达性事实实时追加。
- R03：书籍层骨架：为《齊民要術》《四時纂要》《欽定授時通考》《歲時廣記》《東京夢華錄》《夢粱錄》建 Source（维基文库四庫本入口，直读卷目录，locator 记卷次）；《武林舊事》《農桑輯要》《農政全書》可达性探测。

【阶段1 · 农书体系】R04–R18
- R04–R06：《齊民要術》农时相关篇直读（耕田/收种/种谷等），建 02_shared 农书层卡：农书中的时宜概念、黄河流域农事与节气的互证。
- R07–R09：《四時纂要》逐月农事直读（卷页结构先探），建 shared"逐月农时对照"卡；若卷页不可读，降级为"存目+needs-research"并跳过余下轮。
- R10–R12：《欽定授時通考》时宜/劝农/占候相关卷直读，建 shared 劝农制度史卡。
- R13–R18：六个农时关键节气（立春/雨水/芒种/夏至/秋分/冬至）的农事卡升级：机构层 + 农书直读层双证据，标注"农书成书时代与地域"，禁止把北魏农书写成全国当代农事。

【阶段2 · 岁时记断代链补环】R19–R40
- R19–R30：《歲時廣記》按月逐卷（卷1–12，每月1轮）：当月节气条目直读，产"宋代环节"补环卡（重点：清明寒食中段、上巳、七夕、腊日）。
- R31–R33：《東京夢華錄》直读（立春/冬至/秋社-中秋相邻条目），北宋汴京城市民俗剖面卡。
- R34–R36：《夢粱錄》对读（同题材），南宋临安剖面卡，显式做南北对照。
- R37–R40：断代整合：清明"寒食→清明"宋元明中段链闭合尝试、上巳融入、冬至-腊日关系、既有卡片断代链更新（含立春1914卡若仍无源则维持）。

【阶段3 · 地域民俗扩展】R41–R75（35轮，本轮次主体）
- 目标：RegionalExpression 从 ~8 → ≥48（每节气≥2），七大地域全覆盖：华北/江南/岭南(闽粤桂)/西南/西北/东北/闽台+港澳。
- 每轮 = 1 个地域实践卡：Location/Tradition/Historical Period/Current Practice/Source 五要素齐全；来源优先省级以上非遗名录（ihchina project_details 检索）、香港非遗办、台湾文化资产局（可达性先探）；地方志数据库不可达即记 needs-research 跳过。
- 轮转顺序：先节日型节气（清明R41-42/冬至R43-44/立春R45-46/夏至R47-48），再按地域轮转（岭南→西北→东北→闽台→西南补充→华北补充→江南补充），R49-R75。
- 红线：一个村/县的实践绝不写成"某省都过"；族群表述从官方名录原文；不得把"春节前后"类日期锚写成节气日。

【阶段4 · 数据层】R76–R88
- R76–R78：交节时刻数据：日本国立天文台 24sekki 页扩展直读（近10年+未来10年采样），建 02_shared"逐年交节时刻"数据卡 + "节气间隔不均"分析卡（现代天文解释，补立春卡当年的待办）。
- R79–R83：气候态数据卡：每节气1张"常年气候态卡"（分区域入季日期/气温降水口径），机读源=中国天气网/国家气候中心公开稿；data.cma.cn 需账号→登记人工待办不假装完成。24张分5轮（每轮5张左右，R79春/R80夏/R81秋/R82冬/R83补漏）。
- R84–R86：三候现代验证卡：仅对有公开可靠观测稿的节气做"古典记载vs现代观测"对照，其余明确 needs-research；竺可桢《物候学》未采获前不得引用其数据。
- R87–R88：可视化数据出口：02_shared 建"24节气核心数据表"卡（黄经/日期范围与实例/三候/气候态/习俗地理点），scripts 增加导出 JSON（沿用 pnpm schemas 管线模式），validate 通过。
