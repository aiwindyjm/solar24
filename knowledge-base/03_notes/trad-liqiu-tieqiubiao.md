# 贴秋膘与啃秋：立秋食俗（tradition 层）

## 研究问题

"贴秋膘"的可考文献起点在哪里？流行叙述称其"清代流行"能否成立？啃秋/食秋桃的地域形态如何？

## 证据（按证据等级排列）

1. **机构汇编直读**：非遗网立秋专题（[[04_sources/source-ihchina-liqiu-feature|source-ihchina-liqiu-feature]]）："民间流行在立秋这天以悬秤称人，将体重与立夏时对比。……天气转凉，人们胃口大开，希望增加一点营养，以补偿'苦夏'的损失，补的办法就是吃肉食，'以肉贴膘'，俗称'贴秋膘'。"啃秋条："对城市人家来说，立秋当日买个西瓜，全家围着吃，就是啃秋了。农人的啃秋却是豪放的。……分享各种时令蔬果：西瓜、香瓜、玉米等等。"食秋桃条标注"浙江杭州一带"。
2. **媒体直读**：新华社2022稿（[[04_sources/source-xinhua-liqiu-2022|source-xinhua-liqiu-2022]]，由国庆）："'贴秋膘'就是'以肉贴膘'，人们吃炖肉、烤肉、涮肉等佳肴，用以弥补夏天的身体亏空，此食俗在北方尤其盛行""'咬秋'就是吃西瓜、甜瓜，不仅可以清暑气，还有将秋凉咬住的寓意"；2021稿（[[04_sources/source-xinhua-liqiu-2021|source-xinhua-liqiu-2021]]，罗澍伟）："民间有'立秋'这天'贴秋膘''咬秋''啃秋'等习俗""'贴秋膘'也要恰到好处，不宜过分进补"。
3. **负面文献证据（直读）**：《燕京岁时记》维基文库全页重检索（[[04_sources/source-wikisource-yanjingsuishiji|source-wikisource-yanjingsuishiji]]，2026-09-16 重抓）：全书无"貼""稱人/秤人"字样；七月节下无立秋条；立秋仅见于六月"賜冰"条"京師自暑伏日起至立秋日止，各衙門例有賜冰"。
4. **文献不可得（本轮）**：维基文库 API 检索《清嘉录》《帝京岁时纪胜》无书（与小暑波次日志一致）；《清嘉录》立秋复秤句仅存人民日报转引（见立夏秤人卡）。

## AI 摘要 / 解释

- 谱系结论（当前证据下）：**贴秋膘之名与完整叙事（悬秤对比立夏→苦夏消瘦→以肉进补）在当代机构汇编与媒体稿中高度一致，但可直读的一手文献完全缺位**——常被归诸的清代岁时文献（《帝京岁时纪胜》《清嘉录》）本轮读不到原书，可直读的清末北京《燕京岁时记》里立秋只有"赐冰止于立秋日"的制度性时间标记而无食俗。"清代流行"之说按文献待考处理。
- "悬秤称人对比立夏"与立夏秤人构成**体重年检闭环**（立夏记基数、立秋复秤验损耗）：其文献依据是《清嘉录》转引句（至立秋日又秤之），即复秤行为在清代苏州记载中有影子，但"瘦了吃肉贴膘"的后半段叙事仍无一手文献。
- 啃秋/咬秋为吃瓜防秋燥类食俗（新华社两稿用字不一：2021"咬秋/啃秋"并见、2022只作"咬秋"），地域形态（城市西瓜/农家多样蔬果）为非遗网汇编级。

## 适用条件、例外与分歧

- 无跨来源正面冲突；风险集中在流行叙事把"贴秋膘"写成"自古/清代全国习俗"——本卡的核心记录点正是这一断代缺环。
- 养生提醒（"贴秋膘不宜过分进补""秋瓜坏肚"）属当代健康建议，不入传统层命题。
