# 祈蚕节与小满蚕神诞辰

## 研究问题

"小满是蚕神诞辰"的说法证据有多硬？江浙蚕俗与小满的关系如何分层？

## 证据（按证据等级排列）

1. **古籍直读**（蚕月背景）：《古今图书集成》卷045海宁县条（[[04_sources/source-gjts-suigongdian-045|source-gjts-suigongdian-045]]，见 [[03_notes/hist-gjts-xiaoman-sanche|古籍卡]]）："四月為蠶月……謂之「放蠶忙」，浙西皆然。"——农历四月（含小满所在时段）为蚕月，闭户停讼。
2. **机构"相传"层**：非遗网《小满农俗》（[[04_sources/source-ihchina-xiaoman-nongsu|source-ihchina-xiaoman-nongsu]]）："相传小满是蚕神生日，因此，江浙一带的人们……会在农历四月放蚕时节举行'祈蚕节'。农村会在蚕神庙举办祭祀仪式，城市里售卖丝织品的行业会馆会去专门的祠堂祭祀，并请来戏班唱戏。"
3. **具名史实（机构"据记载"）**：《中国文化报》2015（[[04_sources/source-ihchina-xiaoman-zheli-2015|source-ihchina-xiaoman-zheli-2015]]）：清道光七年（1827）盛泽丝业公所建先蚕祠、演戏三天、点祥瑞戏、"私/死"谐音禁忌。当代活态与建年冲突见 [[03_notes/region-shengze-xiaoman-xi|盛泽小满戏卡]]。
4. **礼制转述**：《小满农俗》："天子亲耕以供粢盛，皇后亲蚕以供祭服"；北海先蚕坛为乾隆帝祭蚕神西陵氏行亲桑礼之建筑——清代国家礼制中蚕桑祭祀的实体证据线索（原典待直读）。

## AI 摘要 / 解释

- 分层结论：**"四月蚕月、蚕事压倒一切"有方志直读**；**"小满=蚕神诞辰→祈蚕节"是"相传"层**（机构汇编、无古籍出处）；**盛泽演戏是可核验的具名史实**（祠存、戏存、年代有说，尽管两歧）。三层不得互相冒充。
- 为什么蚕俗落在小满：《小满农俗》给出现农事逻辑——"时值初夏，蚕茧结成，正待采摘缫丝"——春蚕收茧缫丝正当小满前后，与"动三车"的丝车（[[03_notes/trad-xiaoman-sanche-customs|动三车卡]]）、翁卷"纔了蠶桑又插田"（[[03_notes/lit-wengjuan-xiangcunsiyue|文学卡]]）时间窗一致。
- 谱系警示："蚕神诞辰定于小满"的**断代与成因**（为何选此日）无文献；不得写"自古小满祭蚕神"。

## 适用条件、例外与分歧

- 蚕神身份分歧：文化报/文旅部页语境中的嫘祖（西陵氏）与民间"蚕花娘娘"等称谓系统未做谱系分辨，本轮只记转述。
- 祈蚕节与盛泽小满戏的关系：机构文本把两者并置，但"祈蚕节"作为节名在古籍无征，盛泽演戏有祠可考——本卡把盛泽单独成 region 卡处理。
