# 秋分祭月（夕月）礼制谱系

## 研究问题

"秋分祭月"是可核验的古代礼制还是现代概括？文献链条能直读到哪一级？

## 证据（按文献层级排列，全部为本轮直读）

1. **《礼记·祭义》**（[[04_sources/source-wikisource-liji-jiyi|source-wikisource-liji-jiyi]]）："郊之祭，大報天而主日，配以月。……祭日於壇，祭月於坎；以別幽明，以製上下。祭日於東，祭月於西；以別外內，以端其位。"——日月祭祀的空间对偶（坛/坎、东/西），未系于具体节气。
2. **《文献通考·卷七十九·祭日月》**（[[04_sources/source-wikisource-wxtk-jiriyue|source-wikisource-wxtk-jiriyue]]，辑《周礼》经注疏）："天子常春分朝日，秋分夕月。"又《祭法》："王宮，祭日也；夜明，祭月也。"疏："夜明者，祭月壇名也。"又："此經及下經，皆據春分朝日，秋分夕月。祭日於壇，謂春分也；祭月於坎，謂秋分也。"——二分时点与坛坎祭配在此被注疏传统固定下来；祭月坛得名"夜明"。
3. **应劭注《汉书》**（[[04_sources/source-wikisource-jingkang-xiyue|source-wikisource-jingkang-xiyue]]，《靖康缃素杂记·卷一》转引）："天子春朝日，秋夕月，朝日以朝，夕月以夕。"——后世流传最广的短句的真实文献形态。
4. **《钦定大清会典·卷四十四》**（[[04_sources/source-wikisource-qinghuidian-xiyue|source-wikisource-qinghuidian-xiyue]]）："凡夕月之禮兆陰位於西郊其制一成嵗以秋分迎月出祀夜明以北斗五星二十八宿周天星辰配丑辰未戍年皇帝親夕月奉夜明位東嚮……"卷末坛图："夕月壇陳設圖正位東嚮 夜明之神。"——清代国家祀典明文：每年秋分、西郊夕月坛、祀"夜明"（月神）、星辰配享、部分年份皇帝亲祀。
5. **元稹《秋分日祭百神文》**（[[04_sources/source-wikisource-yuanzhen-jibaishen|source-wikisource-yuanzhen-jibaishen]]，821年）："維長慶元年歲次辛丑八月甲子朔十八日辛巳，皇帝遣……祭於百神之靈……秋序始肅，時將順成，且報且祈，用舉常祀。罔害嘉穀。"——唐代秋分日存在国家层面常祀的实例（祭百神，报收祈谷，**非祭月**，须与夕月礼分开表述）。
6. **机构汇编层**：非遗网秋分专题（[[04_sources/source-ihchina-qiufen-feature|source-ihchina-qiufen-feature]]）："秋分曾是传统的'祭月节'……周代有两分祭日月之说，即春分祭日、秋分祭月。北京的月坛就是明清皇帝祭月的地方。《礼记》载：'天子春朝日，秋夕月。朝日之朝，夕月之夕。'"——叙事框架与古籍链一致，但"《礼记》载"标注不精确（见 finding）。

## AI 摘要 / 解释

- **谱系结论**：礼经（坛坎东西对偶）→ 汉唐注疏传统（春分朝日、秋分夕月的时点配对，祭月坛名"夜明"）→ 清代会典（西郊夕月坛、岁以秋分祀夜明的现行祀典细则）。"秋分祭月"不是现代虚构，是可逐级直读的礼制史命题。
- **finding（出处辨正）**：非遗网"《礼记》载：'天子春朝日，秋夕月'"——直读《礼记·祭义》无此句；《文献通考》辑"天子常春分朝日，秋分夕月"出自《周礼》注疏系统；"天子春朝日，秋夕月"的早期形态是应劭注。机构汇编的出处标注应回溯为"礼经注疏传统"。
- **分立警示**：唐821年秋分日祭的是"百神"（报祈农事），不能挪用为"唐代秋分祭月"的证据；夕月礼与秋分日农祀是并行的两条祭祀线。
