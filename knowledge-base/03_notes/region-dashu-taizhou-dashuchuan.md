# 送大暑船（浙江台州椒江）· Region

## 研究问题

大暑节气最重要的国家级非遗锚点是什么？其地域、谱系与当代实践如何确证？

## 证据（Location / Tradition / Period / Current Practice 四要素）

- **Location（地点）**：浙江省台州市椒江区葭沚街道一带渔村（台州湾南岸、椒江入海口冲积平原）。非遗网项目简介：活动枢纽为以五圣庙为核心的5个庙宇，涉及星光村、星明村、五洲村等多个村落；当地属中亚热带季风区，每年7-9月常有台风、涝灾（[[04_sources/source-ihchina-dashuchuan-project|非遗网项目页]]）。
- **Tradition（仪式）**：送"五圣"（相传为五位凶神）出海、送暑保平安；大暑船按旧时三桅帆船缩小建造、内载各种祭品；2025年现场报道的船长8米、宽2米、重约1.5吨，为"绿眉毛"船式，船身书写"风调雨顺""国泰民安""送暑平安"（[[04_sources/source-xinhua-dashuchuan-2025|新华社2025现场稿]]）。巡游含舞龙舞狮、卖糖担、抬阁、荡湖船、地戏等；江边设坛祭拜后由渔轮牵引至出海口在海上焚烧。
- **Period（时间与谱系）**：每年农历四月开始备料（省级传承人李佩青：四月采购木料竹竿、五月造船、六月底造好）、小暑正式开始活动、大暑日送船，历时约三个月。文献链：俞樾《右台仙馆笔记》卷十二（[[04_sources/source-wikisource-dashu-yutai|维基文库直读]]）："同治中，臨海縣民比年癘疾，過大暑不瘳，乃於次年相約為送船之會，亦其舊俗然也。……前大暑數日，大建道場。至大暑日，送之出海，聽其所之，俗呼為大暑船。"——起源语境为疫病驱遣，且明言"亦其舊俗然也"（此前已有旧俗）；同卷将临海大暑船与休宁四月纸船逐疫俗并置比较。新华社稿据当地史料称清同治年间已有。
- **Current Practice（当代实践）**：2021年第五批国家级非遗扩展项目（Ⅹ-68，母项目"农历二十四节气"2006年第一批，序号516；[[04_sources/source-ihchina-dashuchuan-project|非遗网项目页]]直读名录字段）；保护单位台州市椒江区送大暑船保护中心；浙江省级非遗代表性传承人李佩青（星光村）。2025年7月22日大暑日新华社现场报道：活动当天下午1时开始、近5时下水、渔船拖往东海焚烧；大暑节前村里演戏十天、村民备免费白粥小菜，费用由村民捐助。非遗网简介称参与民众十几万人次、北至宁波南到温州都有人来。

## AI 摘要 / 解释

- 送大暑船是"节气+海洋"双重身份的地方实践：时间坐标来自二十四节气（大暑日为节点、小暑起会），空间与信仰逻辑来自台州湾渔村的海神/瘟神送遣传统。非遗网评价其为"二十四节气农耕文明和椒江地方（海洋）文化共生演化的载体"。
- 与三伏的关系：大暑日送船与"最热时段驱瘟送暑"的时间感受一致（俞樾记"過大暑不瘳"的疫病语境），但仪式本身锚定节气日期而非三伏庚日——与徐州伏羊（锚定入伏，[[03_notes/region-xiaoshu-xuzhou-fuyang|小暑波次卡]]）构成两种不同的历法锚点选择。
- 传播红线：这是特定地域的活态非遗；俞樾笔下的灵异叙事、受访者的明代传说均不得进入产品文案的事实层。

## 适用条件、例外与分歧

- 三个独立发布方（非遗网、新华社、维基文库原书）在核心事实上（椒江葭沚、大暑日送船出海焚烧、清代已有、2021第五批扩展项目）相互印证，无冲突。
- 分歧/待辨：非遗网简介称"每年小暑到大暑节气……举办"，传承人口述为"从小暑正式开始"（造船自四月始）——两口径兼容；"上百年"传承与"同治年间"（1862-1874，距今约150年）为不同精度表述，引用时分开。
- 谱系缺口：俞樾（1890年代成书）与同治年间之间、以及"旧俗"更早形态，无文献；台州地方志核验未做。
