# 《荆楚岁时记》维基文库本 · Source

- 实际读取：是（2026-09-16）。交叉核对：华东师范大学"贴宜春"考、汉典古籍等检索摘要在"立春之日悉剪彩为燕戴之帖宜春二字"上文字一致（"鷵/燕"用字差异已注明）。
- 关键辨析价值：**五辛盘在正月一日条，不在立春条**——大量现代文章把五辛盘直接写作"立春食俗"，与原书文本位置不符。参见 [[03_notes/hist-jingchu-lichun-customs|荆楚立春条笔记]]。
