# 第二轮深度研究计划（Books · Data · Regions · Visualization-data）

定位：第一轮是"网页可达性约束下的广度优先"；第二轮按 [[07_research/solar24-kb-professional-audit|专业审计]] 的缺口清单做深度建设。**不改变 Verified 流程**：一切新增仍走 Evidence Gate，AI 产出最高 verified-candidate。本计划与 P0 人工审核可并行（书籍直读属 Research Material 增量，不阻塞审核）。

## 一、书籍文献层（回应"只调研网页"）

### A 类：岁时文献群补链（✅ 机读可执行——维基文库四庫本，API 已核）

| 书 | 时代/地域 | 对本库的价值 | 产出 |
|---|---|---|---|
| 《歲時廣記》（四庫本） | 宋·类书 | 节日节气的宋代集成叙述，填补唐→清之间的断代中段（如清明卡声明的宋元明缺口） | 全节气断代链补环卡 |
| 《東京夢華錄》（四庫本） | 北宋·汴京 | 都市民俗剖面（七夕/冬至/除夕），与《夢粱錄》对读 | 重点节气城市民俗卡 |
| 《夢粱錄》（四庫本） | 南宋·临安 | 江南民俗剖面，平衡北方文献偏重 | 同上 |
| 《武林舊事》 | 南宋·杭州 | 需先核可达性（未在本次API结果中确认） | 视核验结果 |
| 《欽定古今圖書集成·歲功典》 | 清·类书 | **已在库（批处理已用）**，扩展到全节气分卷 | 每节气补引 |

### B 类：农书体系（✅ 机读可执行——齐民要术/四时纂要/授时通考均有页面）

| 书 | 价值 | 产出 |
|---|---|---|
| 《齊民要術》（北魏） | 农事时宜的祖本；黄河流域农业（与"节气起源于黄河流域"直接互证） | 02_shared 农书层卡 + 各节气农事卡的农书直读环 |
| 《四時纂要》（唐末） | 逐月农事安排，最贴近"节气×农时"结构的农书 | 同上，重点逐月对照 |
| 《欽定授時通考》（清·官修） | 帝国层面的农时总汇（时宜/劝农/占候分类） | 同上 + 劝农制度史补强 |
| 《农桑辑要》《农政全书》 | 视前三种效果再定优先级 | — |

执行方式：按节气黄金模板抽相关卷（不是通读全书），每书建 1 条 Source（带卷次定位），关键节气（立春/雨水/芒种/秋分/冬至等农时节气）优先。

### C 类：现代学术书与地方文献（⚠️ 无合法全文网页——人工采获清单，入审核包待办）

- 竺可桢/宛敏渭《物候学》——三候现代验证的基准（多卡已把它列为待办）
- 萧放《岁时——传统中国民众的时间生活》等岁时节日研究专著——民俗学解释层的学术背书
- 张培瑜《三千五百年历日天象》——逐年交节时刻的权威历表
- （清）顾禄《清嘉录》（苏州岁时）、（清）潘荣陛《帝京岁时纪胜》——维基文库无本，需点校本
- 各省民俗志/《中国民俗大系》——地域层 E 类的纸源底座
- 采获规则：人工购/借后，摘录按 Source（url=null，citation 带出版社/页码）入库——当前协议支持，仅当前无此类来源。

## 二、数据层（回应"缺少数据"）

- **D1 交节时刻历表**（✅ 部分）：日本国立天文台 24sekki 年度页已在库（6源）——扩展为 02_shared"逐年交节时刻"数据卡；紫金山天文台《中国天文年历》为国内法定源（人工采获）。用途：间隔不均分析、日期带可视化。
- **D2 气象气候态**（⚠️ 半人工）：国家气象科学数据中心（data.cma.cn）需账号申请；中国天气网/国家气候中心公开稿可机读但只有文稿级常年值。产出：每节气 1 张"常年气候态卡"（分区域入季日期/气温降水），替代现在 11 张转述卡。
- **D3 现代物候观测**（⚠️ 学术数据）：中国物候观测网/地理所数据需学术渠道；竺可桢历史物候记录在 C 类书内。产出：三候"古典记载 vs 现代观测"对照卡（兑现多个 Needs Research）。

## 三、地域民俗层（回应"各地民俗调研浅"）

- 目标：RegionalExpression 从 ~8 → **每节气 ≥2（≥48 张）**；地域分层：华北/江南/岭南/西南/西北/东北/闽台全覆盖（当前闽粤桂/西北/东北/台湾空白）。
- 来源策略（按可执行性）：① 非遗网 project_details 扩展检索（国家+省级名录，机读可行）→ ② 香港 intangible heritage 香港非遗办页（已知可读）、台湾文化部文化资产局（待核）→ ③ 市县地方志数据库与省民俗志（C 类人工）。
- 优先节气：节日型（清明/冬至/立春/夏至/七夕相邻）先做；每个新地域卡必须带 Location/Tradition/Period/Current Practice 四要素（审核包已立规范）。

## 四、可视化数据层（回应"缺少可视化"——本库只产数据与母题，不产视觉稿）

- **F1 结构化数据卡**：每节气一行核心数据（黄经/交节日期范围与实例/三候/气候常年值/习俗地理点），存放 02_shared 或 scripts 导出 JSON——给未来 Web 层的渲染输入；协议已可承载（ScientificFact + 数据表正文），如需 JSON 走 scripts/export（沿用 schemas 管线）。
- **F2 全景数据集**：24 节气黄道环数据、日期带（1998-2030）、南北入季差、七十二候时间轴——数据源=D1/D2 + 已有 24 张三候卡。
- **F3 视觉母题卡**：VisualAsset 通道已建（当前 0 张）——第二轮产出"母题登记卡"（如冬至消寒图、清明虹桥意象、大暑船、七十二候环），资产仍需版权清理（Experience Gate 不变）。

## 五、执行顺序建议（与审计 P0-P4 对齐）

1. **并行启动**：P0 人工审核（91 张 in-review）‖ 书籍层 A/B 类机读（无互相阻塞）。
2. 书籍层完成后再做数据层 F1/F2（数据卡引用书源与历表更完整）。
3. 地域层 E1（非遗网扩展）可与书籍层并行；E2/E3 随 C 类书籍到位。
4. C 类采获清单与 D2/D3 账号申请：并入 [[07_research/solar24-batch-human-review-package|统一审核包]] 人工待办。
5. 全程遵循 SKILL.md：新增卡片过路由引擎、回归测试不得退化、每步留 batch-log。

## 六、验收判据（第二轮"深度完成"的定义）

- [ ] 每节气新增 ≥1 条书籍直读源（岁时记链或农书）
- [ ] 02_shared 新增农书层 ≥3 卡、断代中段补环 ≥6 节气
- [ ] RegionalExpression ≥2/节气且七大地域全覆盖
- [ ] 每节气 ≥1 张数据级科学卡（时刻/气候态/物候对照其一）
- [ ] F1 结构化数据表导出并通过 validate
- [ ] C 类采获清单全部进入人工待办（不假装完成）
