# Module scaffold template

新模块结构以 [立春](../lichun/README.md) 为参考；当前24模块已建立，不重复生成。

README 按 [统一标准](../../docs/contributing/readme-template.md) 复制叙事，不复制节气事实。manifest 使用对应稳定身份、Planned 状态与 static 能力；内容 draft、claims/sections/references/assets 为空。共享 runtime，不复制 Host 或依赖配置。协议变更先修改 packages/protocol 并同步所有消费者。

有实际创作时，从 [Journey 模板](../../docs/development-journey/journey-template.md)建立该节气的过程记录，并在 README 链接；不用为每阶段预建空文件。声音参与链接 [社区音乐指南](../../docs/community/music-contribution.md)，真实元数据才建 `community/music/<id>.json`，不得复制别的节气投稿或编造作品。
